# 光照场：光池与梦幻光柱（§10.5 / US-11）

> 代码：`src/engine/light-field.js`（场）+ `src/engine/pond.js`（水面绘制）+ `src/engine/koi-renderer.js`（鱼体响应）
> 需求：`REQUIREMENTS_v4.md` §10.5 全表、US-11、§11.2 层 12/13/15/18、附录 A.2 #1–#3
> 尺子：`tools/check-light.js`（数值 49 条）· `tools/_light-break.js`（反证 6 条）· `tools/check-light-ui.cjs`（像素 20 条）
> 实拍：`tools/shot-sunlight-ab.cjs` + `tools/analyze-sunlight-ab.py`

---

## 1. 一句话口径

**「阳光」不是一层贴图，是一个标量场。** 水面怎么画、鱼怎么亮，都只是这个场的一次采样：

```
F-10.5.1  lightAt(x,y) = 底光(夜 .28 / 昼 .36) + 光池 + 光柱 − 云影
```

`LightField` 把这条公式编码成常量 + 一组无状态查询（`poolAt` / `shaftAt` / `cloudAt` / `dreamAt`），
渲染层只读不算。**没有任何"上一帧缓存"能被查询短路** —— 手工放一束柱、单帧渲染、快照回放，
读到的必须是同一个值（`_light-break.js` 有一条专门守这个）。

## 2. 需求里缺的那一项：水色基底 `.31`

需求只列了三项，但验收列同时给了「**暗处 .67**」与「**底光昼 .36**」。
只按 F-10.5.1 求和，暗处只能是 `.36` —— **差出来的 `.67 − .36 = .31` 是水面自己的底色亮度**
（青碧水色本身就在发光）。这不是漏项：附录 A.2 #1「光池铺满无明暗 → **拆底光/光池/光柱**」
说的正是"要把这几项分开算"，其中第一项就是水面底色。

补上之后，需求给的**六个数字同时成立**：

| 项 | 需求 | 实现 |
|---|---|---|
| 暗处 lit（昼） | .67 | `.31 + .36` = **.670** ✓ |
| 池心 lit（昼） | — | `.31 + .36 + .55` = **1.220** |
| 光池验收点 lit | 1.19 | 池心 1.22 减高斯在 **.34σ** 处的落差 = **1.189** ✓ |
| 底光 ≪ 光池 | 显著低于 | `.36` < `.55` ✓ |
| 鱼亮度 | `.44 + .82×lit` | 同式 → 光池 **1.416** / 暗处 **.989** |
| 明暗差 | **1.43 倍** | `1.416 / .989` = **1.431** ✓ |

「1.19 不是池心、而是离池心 **.34σ** 处」这一点是**反推出来的**，不是拍的：
`1.19 = .31 + .36 + .55·e^(−d²/2σ²)` 解出 `d = .335σ` —— 验收采样落在池心旁边一点点，
因为鱼不可能永远压在正中心。这个 `.34` 已经写进 `LIGHT_SAMPLES.pool.offsetSigma`，
**尺子里必须独立抄一份**（见 §5 的"照镜子"坑）。

## 3. ⚠️ 反直觉的坑 #1：两套量纲绝不能混

| | 光场标量 `lit` | 画布颜料浓度 `ink` |
|---|---|---|
| 代表值 | `.55`（光池峰值） | `.16`（光池浓度） |
| 出处 | §10.5 表（F-10.5.2） | 附录 A.2 #2「贡献 .16」 |
| 用在哪 | `fishBrightness()` 算鱼亮度 | `globalAlpha` / 渐变 stop |
| 当 alpha 用会怎样 | **画面立刻白洗** | 鱼亮度算错 |

**把 `.55` 当 alpha 用就是坑本身。** 两者在源码里被刻意分成两组常量：
`LIGHT.*` 在 `light-field.js`，`POOL_INK` / `SHAFT_INK` / `LIGHT_BAND_INK` / `SPARKLE_INK` 在 `pond.js` 顶部。

## 4. ⚠️ 反直觉的坑 #2：canvas 的两个硬约束

- **`screen` / `lighter` 只会加亮，不能压暗。** 压暗必须换回普通合成 + 深色 rgba
  （层 12 明暗带、雨天压暗都走这条路）。
- **纵向淡出只能靠"切片"，不能靠第二个渐变。** canvas 渐变是一维的；
  要同时表达「横向软边 × 纵向进出」必须把带子切成 20 段、每段一个 `globalAlpha`
  （`drawShafts()` 里就是 20 个四边形 + 一个横向 `linearGradient`）。
  少于 12 段会在淡出段看到台阶，多于此纯属白付建路径的钱。
- **碎光要预渲染成精灵。** 26 个点 × 60Hz = 1560 个 `createRadialGradient`/秒，
  而这些点除了位置和透明度完全一样。做法同 `createFishShadow()`。
- **鱼亮度用"乘法调色板"，不是叠白。** 叠 `.22` 的白作用在中间调是 `180×.78 + 255×.22 = 197`，
  只有 ×1.09；乘在调色板上则身体/鳍/头/斑块**一起**按比例走，没有合成模式副作用
  （附录 A.1 #13/#14 都是合成模式来的坑）。

## 5. ★★★ 量具工程：三条"假绿"的坑

这三条是本轮最值钱的经验，**换个人重做几乎一定会再踩一遍**。

### 5.1 "照镜子"式断言 —— 尺子不能从被测模块 import

如果尺子用 `LIGHT.poolSigma` 去算采样点（`池心 + .34σ`），把 σ 从 `.26` 改成 `.08` 时
采样点**跟着缩**，读数纹丝不动 —— 断言永远是绿的。

**解法**：`tools/check-light.js` 里**独立抄一份 `SPEC`**，故意不从 `light-field.js` import。
尺子量的是「实现 ↔ 需求文本」，不是「实现 ↔ 自己」。
再补一条**钉在固定像素上**的断言：`池心 + 260px`（=1σ）必须衰减到 `e^−.5 = .607`、
`+520px`（=2σ）到 `e^−2 = .135`。σ 一破，这条立刻从 `.607` 掉到 `0.005`。

### 5.2 瞬时快照 ≠ 门控

「雨天不出柱」写成 `lf.shafts.length === 0` 是**假绿**：柱子存活 ~9s / 间隔 ~17s，
任一时刻约 **53% 概率恰好为 0** ⇒ 破坏源码后仍有约一半概率变绿。

**解法**：改成**全程累计** `everSpawned()`（破坏后读到 32 束）。

### 5.3 偏窄的区间永远满足更宽的区间

把光柱间隔 `span` 从 `17` 改成 `3`（间隔塌成 9–12s），「都在 9–26s 内」照样成立。

**解法**：判据必须**两头都够得着** —— 上界贴 26s、下界贴 9s（破坏后最大只到 12.000s）。

### 5.4 还有一条工程坑：本环境的托管 `node.exe` 不能再 spawn 自己

`spawnSync` 跑子进程会 `EBUSY`（Windows 锁住正在运行的 exe），
于是"跑一遍看退出码"式反证**整批静默失败**（`e.status === null`，看起来像"五项都没红"）。

**解法**：`check-light.js` 改成**可导出的 runner**（`export function runLightChecks()`），
反证脚本用**带 query 的动态 `import('...?v=N')`** 在同进程重新读盘
（ESM 的模块键是 URL 字符串，加 query 就是另一个模块）。
`tests/light-field.test.js` 复用同一把尺子 —— 一条断言，三个入口都跑它。

## 7. 唯一该动的旋钮：`SHAFT_INK`

需求**没有给光柱浓度**（§10.5 只定了几何与时间）。它是纯观感量，但上下都有硬边界：

- **下界 = 看得见**：0.13 时带心附加 α 只有 .098、带内平均只抬高 3.7 luma，
  铺在密集焦散网纹上肉眼读不出来 —— 等于"功能做了但看不见"。
- **上界 = 不截顶**：滤色叠加等效 alpha `1−Π(1−aᵢ)`，最坏情况「光池 .16 + 两束光柱」同处 = 0.462；
  逐层套下来底色 210 的亮水也只到 244。**F-10.5.2 / 附录 A.2 #2 忌惮的"烧白"不会出现。**
- **取 .20 而不是贴着光池的 .16**：漫射天光与直射光柱不是一个量级，
  一束穿云而下的直射光**本来就该比它照亮的整片水面更亮**。

> 调参必须**只动这一个数**，然后 `check:light:ui`（三条相对判据）+ `shot-sunlight-ab`（重出 A/B）双确认。
> 同时动光池/碎光/暗角，就再也分不清是谁的效果。

## 8. 已知缺口（如实记录，不粉饰）

- **鱼体渲染倍数 1.20–1.24，低于需求的 1.43。**
  光照场本身 **1.431 倍是达标的**；稀释发生在渲染：鱼体由「调色板 + `drawScales` 的固定 alpha 描边
  + sheen + 头部高光」共同构成，后几项不随光照缩放。
  已试过两条路（sheen 高光档 ×gain、sheen 颜色也 lift）都只到 1.22。**归因未定**，
  记为参照读数、不下结论：继续逐层"跟着缩放"是无底洞且会破坏美术意图。
  断言区间据此落实为 **1.15–1.6**。
- **层 3 焦散 UV 流动未做。** 需求要流动，`landscape.js` 的 fragment shader 是死图
  （注释原文：`No displacement or oscillating lighting is applied to the water...`）。要动 WebGL。
- **层 11 水面风纹 / 层 14 大气 LUT / 层 16 夜间池灯** 未做（需新素材）。
- **层 10 flora 绘制顺序倒置**（鱼压在荷叶上）—— 唯一明确的需求违背。

## 9. 附：核对本功能时踩到的**启动**坑

（与光照无关，但都在本轮核对真机时撞上，记下来省下一次重踩）

| 症状 | 根因 | 正解 |
|---|---|---|
| `vite build` 在 `prepare-out-dir` 阶段失败：`SAFE_DELETE_BULK_CONFIRM_REQUIRED` | 构建要清 `dist/`，批量删除闸门拦住了 | 先 `mv dist .dist-old-$(date +%H%M)` 再构建 |
| `mv dist ...` → Permission denied | 上一轮遗留的 electron 还持着目录 | 先结束本项目 electron 进程再改名 |
| 换了 `--user-data-dir` 后窗口再也不出现，日志只有一行 `DevTools listening` | 路径用了**正斜杠** ⇒ `main.cjs:407` 的 `requestSingleInstanceLock()` 拿到 false ⇒ `app.quit()` **静默退出** | 用 Windows 反斜杠路径；现在 `tools/launch-desktop.cjs` 支持 `POND_USER_DATA_DIR` |
| 干净房间启动后 `PrintWindow` 返回 0，看着像"抓不到画面" | 窗口是**最小化**状态（矩形典型的 `159×27`） | 抓之前先 `ShowWindow(SW_RESTORE)`；`tools/scan-sunlight.py` 已内置 |
| 在真实窗口里"自动找光柱"总挑到连号帧 | 用**暖偏残差**挑帧会被**橙红色的锦鲤**污染 —— 它们才是画面里最暖的东西 | 别在真实窗口里靠残差找柱子；要判观感就用 `shot-sunlight-ab.cjs` 的同帧控制 A/B |
| 关底图后差分噪声反而暴涨（1.95 luma） | `display:none` 会**改布局** ⇒ `.pond-canvas` 重排重画 | 用 `visibility:hidden`（保留占位） |
